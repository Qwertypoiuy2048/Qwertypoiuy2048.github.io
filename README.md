# Qwertypoiuy2048.github.io

Personal GitHub project homepage for [Qwertypoiuy2048](https://github.com/Qwertypoiuy2048).

The site is a dependency-free GitHub Pages website. The homepage has a curated Featured Projects section, a three-project Recent Projects section, and `projects.html` lists all public repositories. Project cards are loaded from the GitHub public repositories API at runtime.

To curate the homepage, add 3-6 repository names, `owner/repository` references, or full public GitHub URLs to `FEATURED_REPOSITORIES` in `script.js`. This supports group and organization repositories too. Leave it empty to use the three most recently updated repositories as the default.
